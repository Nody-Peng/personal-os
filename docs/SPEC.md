# Personal OS 個人成長平台 規格書

> 版本日期：2026-10-04
> 線上版（可留言、編輯）：https://claude.ai/code/artifact/37b3a6a7-5bc1-4940-97da-97f4ec52f577

## 概述

Personal OS 是一個以我為中心的私人平台。它把每日打卡、托福進度、想學清單和週回顧集中在一個地方，首要任務是在 2027 年 1 月初的托福考試前，把總分從約 3.5 級提升到 5.0 級（新制 1–6 級分；舊制約 70 → 95–106 分）。

### 背景

- 社會新鮮人，WebGIS 工程師；週一至週五 9:00 上班，通常 19:00 下班
- 可運用的時段：07:20–08:10 聽英文、22:00–24:00 完整時段、週末
- 長篇筆記放在 Notion；上班時間學 AI 和架構
- 口說和寫作是托福最需要加強的兩科

### 目標

1. 托福總分約 3.5 → 5.0 級（13 週，CEFR B1 → C1）
2. 每週的主題選擇有依據、可以回頭檢視
3. 進步看得見：同時追蹤過程指標和成果指標
4. 長期來看，累積的資料可以變成 CV 和作品集的素材

### 非目標（考完托福前不做）

- 完整取代 Notion：筆記本只做頁面、子頁面、區塊編輯、搜尋和垃圾桶；資料庫檢視（表格、看板）不做，圖片上傳和頁面互連等考完托福再評估
- 多使用者或社群功能
- 原生 App（PWA 就夠用）
- 行事曆雙向同步

### 成功指標

| 指標 | 標準 |
| --- | --- |
| 使用率 | 13 週內每日紀錄的填寫率 ≥ 85% |
| 輸入成本 | 每日打卡 ≤ 10 秒 |
| 托福檢查點 | 第 4、8、12 週模考總分分別 ≥ 4.0、4.5、5.0 級 |
| 週回顧 | 13 週內完成至少 12 次 |
| 開發時間 | 不佔用 22:00–23:00 的托福時段和週六的托福練習 |

## 使用情境與核心循環

平台不幫你新增時段，只幫已經存在的時段設定用途、留下紀錄。每個時段對應一個頁面或顯示模式。

### 時段配置

| 時段 | 用途 | 平台角色 |
| --- | --- | --- |
| 07:20–08:10 | 英文聽力（Flip5 自動播放） | Kiosk 顯示今日重點和考試倒數 |
| 9:00–19:00 | 上班、學 AI 和架構（Notion 筆記） | 不介入 |
| 下班後到 21:30 | 健身（每週 3–4 次）、做飯 | 打卡 |
| 22:00–23:00 | 托福核心：週一口說、週二寫作、週三閱讀和單字、週四口說、週五寫作 | 計時、AI 教練、時數紀錄 |
| 23:00–24:00 | 本週主題（每週日決定） | 顯示主題、記錄時數 |
| 週六 | 托福刻意練習 3 小時：口說 60 分、寫作 60 分、小測驗 30–60 分 | AI 教練、測驗分數 |
| 週日 | 週回顧 30–45 分鐘 | 週回顧頁 |

和女友的通話（起床、12:30、24:00）不排任何任務，平台也不追蹤。

### 四種循環

| 循環 | 時間 | 動作 | 使用的頁面 |
| --- | --- | --- | --- |
| 隨時 | 想到就記 | 想法先放進想學清單，不馬上行動 | 快速輸入 |
| 每日 | 24:00 關機儀式 | 打卡、寫 3 行筆記、定明天最重要的一件事 | Today |
| 每週 | 週日 | 看數字、替想學清單評分、選下週主題、定 3 個關鍵成果 | 週回顧 |
| 每 4 週 | 第 4、8、12 週的週六 | 完整模考、對照目標線、依規則調整 | 托福 |

### 事先定好的調整規則

- **第 6 週**：模考總分 ≤ 4.0 → 週一和週四的 23:00–24:00 也改練托福
- **第 10 週**：模考總分低於 4.5 → 考慮延後考試或調整目標分數
- **主題**：選定後至少做滿一週
- **功能**：做好後兩週沒使用就刪除

這些規則由平台在週回顧頁自動提醒。

## 技術架構

採用單一個 Next.js 專案，Payload 直接內嵌在裡面，部署到 Vercel，資料存在 Supabase 的 PostgreSQL。這是你已經熟悉的技術，不引入新框架。

| 層 | 技術 | 說明 |
| --- | --- | --- |
| 前端 | React + Next.js（App Router） | 私人區、公開區、Kiosk 共用同一個專案，用 route group 分開 |
| CMS 與 API | Payload（內嵌在 Next.js） | collections、登入驗證、存取控制、後台 `/admin`；頁面用 Local API 讀資料 |
| 資料庫 | Supabase PostgreSQL + `@payloadcms/db-postgres` | 用 Supabase 的連線池（pooler）連線，配合 serverless |
| 檔案儲存 | Supabase Storage（S3 相容）+ `@payloadcms/storage-s3` | 口說錄音、CV 圖片；錄音放在私人 bucket |
| 部署 | Vercel | 推到 main 就自動部署；Vercel Cron 每天跑定時任務 |
| AI 評分 | Claude API | 口說和寫作評分、週報草稿；只在伺服器端呼叫 |
| 語音轉文字 | 待選（例如 Whisper 系列 API 或 Deepgram） | Claude 不直接接收音檔，需要先轉成文字 |
| 圖表 | Recharts 或你慣用的圖表套件 | 托福分數與目標線 |
| 手機 | PWA（manifest + service worker） | 主手機和 Flip5 都加到主畫面 |

### 專案結構

```

  (private)/        Today、托福、教練、想學清單、週回顧、健身（需登入）

  kiosk/            Flip5 顯示頁（唯讀權杖）
  (payload)/        Payload 後台與 REST/GraphQL

  api/cron/         週日快照、提醒

### 免費方案的限制

- **Supabase 免費專案長時間沒有活動會暫停**。每天使用就不會發生，但考完試後要注意。
- **Vercel Hobby 的函式執行時間有上限**。轉文字和評分分成兩個請求，音檔限制在 2 分鐘內。
- 實際額度以兩家官網公告為準。

### Today（`/`）

目標是 **10 秒內完成打卡**，且主要在手機上使用。

- 頂部：距離考試天數、本週主題、今天最重要的一件事（來自昨天的 `tomorrowTop1`）
- 三個大按鈕切換：早上聽力、健身、托福
- 托福時數快鍵：+15 / +30 / +60 分鐘；科目預設為 `weekPlan` 當天的科目
- 3 行筆記、明天最重要的一件事、精力 1–5
- 自動儲存，不需要按「送出」
- 本週小統計：健身 x/3、托福 x/8 小時

### 托福（`/toefl`）

- 折線圖：實際級分點 + 從 3.5 到 5.0 的目標線，檢查點用菱形標示
- 可切換「總分」與「單科」兩種檢視
- 每週托福時數長條圖（目標 8 小時）
- 新增分數的表單：類型、來源、四科級分；四科都填時即時顯示總分、CEFR 與舊制對照
- 後續（v3）：最常見的 5 種錯誤類別

### 想學清單（`/ideas`）

- 一行快速輸入：標題加原因，Enter 就存；也提供 PWA 捷徑直接開啟輸入框
- 評分時用 0–3 的點選，總分自動計算
- 依 `status` 分頁籤；收件匣依總分排序

### 週回顧（`/review/[week]`，v2）

1. 自動帶入本週數字：托福時數、健身次數、聽力天數、測驗分數、本週主題時數
2. 到第 6 週或第 10 週時，若分數低於門檻，顯示調整規則提醒
3. 寫反思：哪一天斷掉、原因是什麼
4. 想學清單評分 → 選下週主題並寫原因
5. 定下週 3 個關鍵成果
6. （v3）AI 根據本週紀錄寫週報草稿，並提出 3 個反思問題

每月第一個週日加一個區塊：列出過去 4 週選的主題和原因，幫助你歸納自己的決策模式。

## AI 教練設計

AI 教練是整個平台最有價值的功能：它把「練習、回饋、針對弱點重做」串成一個流程，也就是《刻意練習》的核心。題型依 2026 年 1 月改版後的托福設計。

### 口說：Take an Interview

1. 從 `prompts` 題庫抽一題（熟悉主題：學校、工作、科技、生活），預設優先抽較久沒練的主題
2. 顯示題目並用 TTS 唸出，然後倒數 45 秒錄音（瀏覽器 MediaRecorder）
3. 音檔上傳到 Supabase Storage 的私人 bucket
4. 語音轉文字
5. Claude 依評分標準回傳 JSON：估計級分、各面向分數、最多 3 個錯誤及修正、**1 個下次要練的重點**、範例回答
6. 錯誤自動寫進 `error-log`
7. 「同題重講」按鈕：同一題最多重講 3 次，並排在一起比較分數

### 口說：Listen and Repeat

1. 用 TTS 播放一句題庫句子（只播一次）
2. 錄下你的複述，轉成文字
3. 和原句比對，算出逐字準確率，標出漏掉或說錯的字
4. 一組 7 句，結束後顯示平均準確率

限制：轉文字只能判斷「說了哪些字」，判斷不了發音和節奏。若需要發音評分，可以評估專門的發音評測 API（例如 Azure Pronunciation Assessment）。

### 寫作：Email 與 Academic Discussion

1. 抽題，開始限時寫作（時間可在 `settings` 設定，對齊官方規定）
2. 時間到自動送出；Claude 回傳估計級分、逐句修改、結構建議
3. 錯誤寫進 `error-log`
4. 重寫一次後再評分，顯示前後差異

Build a Sentence 是單純的重組句子題，不需要 AI 評分，用題庫加標準答案即可。

### 提示詞架構

| 部分 | 內容 |
| --- | --- |
| System | 角色（托福評分員）、該題型的評分標準全文、輸出的 JSON schema、語氣（直接、具體） |
| 個人化 | `error-log` 中最常見的 5 個錯誤類別，請 AI 特別檢查這些 |
| 使用者內容 | 題目、你的回答（逐字稿或作文）、練習次數 |
| 輸出 | 結構化 JSON，用 Zod 驗證；驗證失敗就重試一次 |

模型建議：評分用 Claude Sonnet 5.5，週報草稿等輕量工作用 Claude Haiku 4.5。

### 校準

AI 分數只是**估計值**，要定期校準：做 ETS 官方練習題時，把同一份回答也交給 AI 評分，記錄兩者差距。如果 AI 一直偏高或偏低，就調整提示詞。

## Flip5 顯示模式與自動化

Flip5 半折立在桌上、充電時常亮，顯示 `/kiosk`；定時動作交給 Samsung 內建的「模式和日常程序」，不必另外寫程式。

### `/kiosk` 依時段切換內容

| 時段 | 顯示 |
| --- | --- |
| 07:20–08:10 | 「聽力時間」、今天最重要的一件事、距離考試天數 |
| 22:00–23:00 | 「托福時間」、今天的科目（來自 `weekPlan`）、最常見的 1 個錯誤 |
| 23:00–24:00 | 本週主題及本週累積時數 |
| 24:00 之後 | 「關機儀式」提示、今天是否已打卡 |
| 其他時間 | 時鐘、考試倒數、本週健身次數 |

實作重點：

- 深色背景、大字，1 公尺外看得清楚
- Wake Lock API 讓螢幕保持亮著；每 5 分鐘重新取資料
- 用網址上的 `kioskToken` 驗證，**唯讀**，可隨時在 `settings` 重新產生
- 時段判斷一律用台灣時間（Asia/Taipei）

### Samsung 日常程序

| 觸發 | 動作 |
| --- | --- |
| 每天 07:20 | 調高媒體音量 → 播放英文聽力歌單（到 08:10 自動停止） |
| 週一至週五 22:00 | 開啟勿擾（女友設為例外）→ 開啟 Personal OS（PWA） |
| 每天 24:00 | 關閉勿擾 → 顯示關機儀式提示 |
| 充電中 | 螢幕常亮（搭配 Wake Lock） |

### 其他用途

- **錄音錄影**：口說教練可以直接在 Flip5 開，半折立著錄自己的回答
- **外螢幕**：可以放一個捷徑，快速開啟想學清單輸入框

## 隱私與安全

預設所有資料都是私人的，只有你主動標記為「已發布」的 CV 和作品集內容會公開。

| 項目 | 做法 |
| --- | --- |
| 存取控制 | 每個 collection 都寫 Payload `access` 函式；私人 collection 的讀寫都要登入，公開 collection 只開放 `status = published` 的資料 |
| 登入 | Payload 內建驗證；關閉公開註冊，只有一個帳號 |
| Supabase 公開 API | 所有資料表都**開啟 RLS** 且不設政策，或直接關閉 Data API。否則持有 anon key 的人可能讀到資料 |
| 錄音檔 | 私人 bucket，播放時用短效簽名網址 |
| Kiosk | 唯讀權杖，只讀得到 Kiosk 需要的欄位，可隨時重新產生 |
| API 金鑰 | 只放在 Vercel 環境變數，只在伺服器端使用，不進 git |
| 公開個資 | CV 不放電話、地址等資訊；聯絡方式用表單或 email 別名 |
| AI 服務 | 送出的只有題目、你的回答和錯誤類別，不送每日筆記 |
| 備份 | 每週用 GitHub Actions 跑 `pg_dump`，備份存到私人位置（免費方案的自動備份有限） |
| 錄音保存期限 | 預設保留 90 天後刪除音檔，逐字稿和分數永久保留 |

## 開發里程碑與驗收標準

開發只用每週的 23:00–24:00 主題時段和週日下午，不動用 22:00 托福時段和週六練習。

```
MVP       10/5–10/11   Today 打卡、托福分數與目標線、想學清單

   ◆ 關卡：10/25 在平台完成第一次週回顧

開發凍結  11/9–考試    只修錯誤，不加新功能
