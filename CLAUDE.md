# Personal OS

Single-owner personal platform (daily check-ins, TOEFL progress, learning backlog). Product spec: `docs/SPEC.md` (Traditional Chinese). UI copy is Traditional Chinese.

## Stack & commands

- Next.js 16 App Router + Payload 3 embedded + Postgres (`@payloadcms/db-postgres`), Tailwind v4, Phosphor icons. Deploy: Vercel + Supabase.
- Local DB: `npm run db:local` (embedded Postgres on 54322). Dev: `npm run dev`. Tests: `npm run test:int` (needs local DB). Also `npm run lint`, `npx tsc --noEmit`.
- Payload reference: `.claude/skills/payload/SKILL.md`.

## Conventions

- **Days** are Taiwan-local `YYYY-MM-DD` strings with a **04:00 day boundary** (`src/lib/day.ts`, `logicalDay()`); never use `Date` objects or Payload `date` fields for days.
- **Access**: every private collection uses `authenticated`. Frontend pages call `requireSession(path)`; server actions call `requireActionSession()` and pass `user` + `overrideAccess: false` to the Local API.
- Server actions live in `src/app/(frontend)/actions.ts`, whitelist and clamp every input, and return `ActionResult`. Validate days/months with `isDay`/`isMonth` (real calendar dates), not the bare patterns. Save "the one row for this key" (a day log, a week or month note) with `upsertOne` (`lib/upsert.ts`), which survives two saves racing to create it.
- Option lists shared by schema and UI are in `src/lib/options.ts`.
- **Journal**: daily IMPORTANT items (max 3/day) and weekly to-dos are one `tasks` collection (`src/lib/tasks.ts`); unfinished IMPORTANT items are migrated with `moveTaskToNextDay` (original keeps status `migrated`; one transaction, `migratedFrom` is unique, and a migrated original can't be ticked again). 早/午/晚 are day-only checklists (`daily-logs.morningItems`/`noonItems`/`eveningItems`, `lib/dayParts.ts`), never counted in stats: a day counts as recorded only per `isRecordedLog` (`lib/dailyLog.ts`). Journal server actions live in `src/app/(frontend)/journal-actions.ts`.
- **Rich text** (task bodies, daily note, week/month reviews) is BlockNote JSON stored in Payload `json` fields, edited with `components/editor/BlockEditor` (client-only, autosaves). Use `lib/blocks.ts` to read plain text. When `initial` comes from a server page, also pass `renderedAt={renderStamp()}`: `lib/noteCache.ts` then keeps back/forward (and a page opened before a save landed) from showing, and re-saving, stale content. Client state seeded from server props (e.g. `DayLogProvider`) uses the same `withLocal` / `rememberLocal` / `useRenderStamp`.
- **Habits** are a `habits` collection (max 4 active; archive instead of delete so history stays); a day stores ticked habits in `daily-logs.habitsDone`. Use `habitIdsOf` / `habitsForPeriod` from `lib/queries.ts`.
- **Week themes** live on each week note (`weekly-reviews.theme`); the current week's theme is mirrored as idea status `selected` (`lib/weekThemes.ts`, `getCurrentTheme`).
- **Notebooks** (`notebooks` + `note-pages`, `src/lib/notes.ts`): Notion-like pages nested via `parent`, BlockNote JSON in `content` with a `plainText` copy (set by the collection hook) for search. A page's `kind` is `page`, `board` (a todo database) or `item` (a board card: `status`, `startDate`/`endDate`, `parentItem`; parent = its board). Items are hidden from the sidebar tree (and can't be moved there or hold pages); boards load through `lib/boardStore.ts` (versioned: a load that raced an optimistic edit reloads) and cards open in the side peek (`?peek=<id>`, `board/ItemPeek`). A page's look (`font`, `smallText`, `fullWidth`, `locked`) and `favorite` are set from `notebooks/PageMenu`; `duplicatePage` copies a subtree in one transaction and remaps sub-page/board blocks in the copied content. Deleting uses Payload's built-in trash (`trash: true`, `deletedAt`); a page and its subtree share one `deletedAt` so they restore together. Server actions live in `src/app/(frontend)/notebook-actions.ts`; the notebook view (`/notebooks/[id]/[pageId]`) has no AppNav and keeps its tree in client state (`NotebookShell`), with `lib/noteCache.ts` guarding against stale back/forward payloads.
- **Editor schema** (`components/editor/schema.tsx`): default blocks + callout, toc, pageLink (`mode` child = sub-page created in the text / link = any page), board (a link outside a notebook), bookmark (`blocks/BookmarkBlock`: metadata fetched once by `getLinkPreview` in `link-actions.ts` and stored in the block; `lib/linkPreview.ts` asks as Slack's, then Facebook's, link unfurler since many sites only answer those), embed (`blocks/EmbedBlock`; `lib/embeds.ts` maps YouTube/Maps/Docs/Figma… to frame URLs; any other site is checked with `getFramePolicy` first and, if it refuses frames, offers a bookmark instead of an empty box), and `@blocknote/xl-multi-column` columns (GPL-3.0; fine for this private site). Notebook-aware blocks read `NoteContext`. Slash items are ranked exact → prefix → contains and kept grouped (`rankItems`); `notionShortcuts` makes `> ` a toggle (quote is `" `) and ```` ``` ```` a code block, and its Enter (`editor/toggleEnter.ts`) keeps a toggle's children with it (open → new first child, closed → new toggle below). An open toggle whose last child isn't text leaves a strip below it (styles.css) that adds a line when clicked, as does the space under a short column (`lineBelow` in `blockSelection.ts`). Pasting a lone URL asks keep / bookmark / embed (`editor/PasteUrlMenu`); `:` opens the emoji grid (`editor/emojiItems`); the ⋮⋮ menu is `editor/BlockMenu` (duplicate, copy block link → `#block-<id>`). Export/import (Markdown, HTML) is `lib/exportNote.ts`.
- **Code blocks** replace BlockNote's `codeBlock` render with `blocks/CodeBlock` (language picker + copy at the top right, default Bash). Languages are listed in `editor/codeLanguages.ts`, and each needs a grammar in `editor/codeHighlighter.ts` (Shiki, JS regex engine, `@shikijs/langs`; the precompiled grammars mis-tokenize).
- **Page icons** are an emoji, `ph:<name>:<colour>` (a Phosphor icon, `lib/noteIcons.ts`) or an uploaded picture's `/api/media/file/…` URL, all validated by `cleanNoteIcon`. Always render them with `notebooks/NoteIcon` (emoji use the shared `--font-emoji` stack: Apple, then Noto Color Emoji from `layout.tsx`). The picker's emoji list is generated by `npm run emoji` (emojibase-data, zh-Hant names).
- **Block selection** (`components/editor/blockSelection.ts`): Notion-style box select from the margins (an ancestor with `data-block-select-zone` widens the area). The selection is a ProseMirror `BlockSelection` (a run of sibling blocks); while it is active, keys go to a hidden `.block-select-sink`, and `BlockMenu`'s drag handle widens BlockNote's one-block drag to all selected blocks.
- **Media**: `media` upload collection, private. Production uses Supabase Storage through `@payloadcms/storage-s3` (`S3_*` env vars; browsers upload directly with signed URLs, downloads redirect to signed URLs); without `S3_BUCKET` files go to `./media`. The plugin is always registered (`enabled` + `alwaysInsertFields`) so the schema doesn't depend on env. Upload with `lib/uploadMedia.ts` (shrinks photos to JPEG ≤ 2400px and always converts WebP, which Payload would re-encode and orphan the original; page icons pass `{ maxSide: 512, keepAlpha: true }`).
- **Bookshelf** (`/journal`): journals and notebooks share `components/books/BookCover` (colours and CSS patterns in `lib/options.ts`, styles under `.cover-cloth` in `styles.css`). `BookLink` plays the open-the-book animation via `BookOpenProvider` in the root frontend layout.
- **Login** is the custom `/login` page (Payload REST login); `/admin/login` remains for the admin. Use `safeRedirect` (`lib/safeRedirect.ts`, re-exported from `lib/session.ts`) for any post-login target.
- **Security**: each production boot enables RLS on every `public` table (`onInit` in `payload.config.ts`; Payload connects as the owner, so no policies are needed). The CSRF allowlist is opt-in via `NEXT_PUBLIC_SERVER_URL`; never set `serverURL` (it makes media URLs absolute). Anything the server fetches for a user-given URL goes through `lib/linkPreview.ts` (public addresses only, checked when connecting).
- The task side panel is URL-driven (`?task=<id>`, `lib/useTaskPeek.ts`); the month calendar opens week notes with `?week=<monday>`. Open/close URL panels with `lib/panelHistory.ts` (closing steps back over the entry it opened). Panels that close on Esc skip it while `escapeHandledElsewhere()` (`lib/escape.ts`); mark anything that handles its own Esc with `data-own-escape`. `fixed` popovers render in a portal (a blurred sticky header would otherwise be their containing block).
- **TOEFL scores use the new (Jan 2026) scale only**: sections 1–6 in 0.5 steps, overall = average of four sections rounded to nearest 0.5, computed in the `toefl-scores` hook. All scoring logic and the ETS concordance (CEFR, old 0–120 range) live in `src/lib/toefl.ts`; never store 0–120 scores.
- **Schema changes**: run `npm run generate:types`, then `npm run payload migrate:create <name>` and commit `src/migrations/*` (production applies them via `prodMigrations`).
- **Design**: follow `.claude/skills/minimalist-ui` (warm monochrome, 1px `#EAEAEA`-style borders, radius 8/12, one accent `--color-accent` for interaction and chart marks, pastel pairs only for small semantic tags). Tokens are in `src/app/(frontend)/styles.css`, redefined for dark under `[data-theme='dark']` (`lib/theme.ts`: 跟隨系統/淺色/深色 per device, set before paint by `THEME_SCRIPT`), so never hard-code a colour: text on an ink/accent fill is `text-on-ink`, dialog backdrops `bg-scrim`, icon colours `--color-icon-*`; the editor gets `theme={useResolvedTheme()}` and code uses Shiki's light/dark pair. Phones: no sideways page scroll at 375px, ≥40px tap targets, `md:` for desktop density; motion classes (`pop-in`, `page-in`, `check-in`, `sheet-in`…) all stop under `prefers-reduced-motion`. Charts follow the dataviz rules: hand-rolled SVG at real pixel width (`useElementWidth`), hover tooltips, text never in series color.
